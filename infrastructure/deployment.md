# Cara memasang aplikasi pada VM (contoh, belum diuji)
1. Pastikan backend/API selesai dan tes lulus. Di laptop pengembang dengan Node.js 22.18+ seri 22, dari frontend jalankan npm install, npm run build. Setelah lockfile tersedia gunakan npm ci. Salin repo dan folder frontend/dist ke VM secara privat (mis. SCP). Jangan commit dist.
2. Pada Ubuntu khusus BankGuard, dari folder repo jalankan sudo bash infrastructure/setup.sh. Script memasang paket, menyalin kode/build ke /opt/bankguard dan menyiapkan service. Belum mengaktifkan service atau situs.
3. Buat /etc/bankguard/bankguard.env melalui sudo install -m 600 /dev/null /etc/bankguard/bankguard.env HANYA jika belum ada; edit dengan sudoedit. Isikan BANKGUARD_SECRET_KEY (acak, unik), BANKGUARD_DEMO_USER, BANKGUARD_DEMO_PASSWORD_HASH (hash Werkzeug, bukan password asli), BANKGUARD_DB_PATH=/var/lib/bankguard/bankguard.sqlite3, BANKGUARD_COOKIE_SECURE=0 untuk HTTP demo. Jangan gunakan password asli; gunakan HTTPS untuk lingkungan nyata. systemd EnvironmentFile tidak sama dengan script shell; kutip nilai dengan benar. Buat rahasia lokal, jangan commit atau screenshot.
4. Pada VM yang memang khusus BankGuard, periksa /etc/nginx/sites-enabled. Nonaktifkan symlink default bawaan bila ada (jangan hapus situs lain), aktifkan symlink /etc/nginx/sites-available/bankguard ke /etc/nginx/sites-enabled/bankguard. Jalankan sudo nginx -t; jika berhasil sudo systemctl enable --now nginx dan sudo systemctl reload nginx.
5. Jalankan sudo systemctl enable --now bankguard, periksa sudo systemctl status bankguard, lalu curl http://127.0.0.1/api/health dan buka http://IP-VM/ melalui browser/jaringan yang disiapkan. Uji login dan simulasi; jika gagal cek sudo journalctl -u bankguard. Port 8000 hanya loopback.
6. Sebelum clone: matikan service backend, hapus data demo dan secret hanya pada template yang telah disepakati (cadangkan jika diperlukan); nonaktifkan service sampai identitas clone dan environment unik disiapkan. Matikan VM. Pada setiap clone buat identitas unik dan environment baru sebelum enable/start bankguard. Uji ulang.
7. NAT host 8081–8083 → guest 80. Lihat network.md. Tidak perlu server Vite/Node.js berjalan di VM.
