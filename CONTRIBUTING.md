# Kolaborasi pemula
1. Terima undangan repository, instal GitHub Desktop dan VS Code. Tim kode/QA instal Python 3.12; hanya tim infra perlu VM.
2. GitHub Desktop > File > Clone repository; pilih repo ini. Repository > Open in Visual Studio Code.
3. Current branch > main > Fetch/Pull origin; pilih branch peran yang sudah dibuat. Branch > Merge into current branch > main sebelum bekerja; simpan perubahan dahulu.
4. Baca Issue dan kontrak. Latihan: buat docs/members/<role>.md berisi peran dan tugas (tanpa nama pribadi saat Public).
5. Save, periksa Changes, commit pada branch sendiri, Push origin. Buat Pull Request base main, compare branch sendiri. Cantumkan perubahan dan hasil uji aktual.
6. Ketua review Files changed, uji dan merge; jangan hapus branch yang masih dipakai. Jangan push langsung ke main. Konflik: koordinasikan, jangan timpa kode teman.
7. Jangan unggah rahasia, data nyata, ISO/VDI atau rekaman besar. Simpan bukti sensitif terpisah. Jangan klaim lulus sebelum diuji.

Urutan: kontrak → database/scoring → backend/frontend → QA → template → clone → jaringan → demo. Infrastruktur berjalan paralel.
